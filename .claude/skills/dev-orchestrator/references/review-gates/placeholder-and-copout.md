# Review gate: placeholder + copout

## Placeholder phrases (any occurrence is a violation)

- `TBD`
- `TODO`
- `fill in`
- `details to follow`
- `Similar to <other>` (with no concrete reference)
- `Add appropriate <X>`
- `handle edge cases`
- `placeholder`
- `implement later`

## Copout phrases (occurrence in main body of plan/spec/report is a violation; appearance only in an explicit §Out-of-scope section with a one-line justification is allowed)

- `pre-existing`
- `out of scope` without justification of why this scope edge
- `covered elsewhere`
- `engine-proven by prior phase`
- `math is unit-tested`
- `will file in BACKLOG later`
- `quick workaround`

For each violation: cite section + quote the phrase + rule violated. Status `rejected` if any violation in the main body.
