# Review gate: placeholder

## Placeholder phrases (any occurrence is a violation)

- `TBD`
- `TODO`
- `fill in`
- `details to follow`
- `Similar to <other>` (with no concrete reference)
- `Add appropriate <X>`
- `handle edge cases`
- `placeholder`
- `implement later`

For each violation: cite section + quote the phrase + rule violated. Status `rejected` if any occurrence.

Self-deferral / copout / substitution rationales are a separate concern — see `forbidden-rationales.md`.
